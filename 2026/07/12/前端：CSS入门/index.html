常用属性

字体属性

字体颜色

color，值可以是单词、十六进制、rgb函数、rgba函数。

单词：red、green、purple等。

十六进制：#ff0000，这个是红色。

rgb函数：rgb(r,g,b)

rgba函数：rgba(r,g,b,a)，最后一个参数a表示不透明度，是[0,1]的浮点数，0表示完全透明。

字体大小

font-size，值为"xx px"，xx是字号。Chrome浏览器接受的最小字号是12px。

字体粗细

font-weight，值可以是单词"bold"（加粗）、“bolder”（更粗）、“normal”（默认）、"lighter"更细。也可以是整数值[100,900]，400=normal，700=bold。

字体样式

font-style，值可以是"normal"（默认）、“italic”（斜体）。

字体效果

font-family，值可以是中文或英文的字体的名称，如"微软雅黑"、“Microsoft YaHei”、"Simsum"等。默认字体就是微软雅黑。

背景属性

长宽

width、height，值的单位是像素，不做赘述了。

背景颜色

background-color，值和上文提到的字体颜色一样，有四种：

单词：red、green、purple等。

十六进制：#ff0000，这个是红色。

rgb函数：rgb(r,g,b)

rgba函数：rgba(r,g,b,a)，最后一个参数a表示不透明度，是[0,1]的浮点数，0表示完全透明。

背景图片填充

background-image，值需要调用url()函数，参数为一个字符串，标识了索引图片的路径。

重复性

background-repeat，默认是x-y无限重复填充。

可以把值改为x-repeat、y-repeat、no-repeat，实现水平重复、竖直重复、不重复。

背景图片大小

background-size，值可以是两个整数+px，也可以是两个百分比，也可以是cover（保持图片不变形，充满整个容器，会把图片多余部分切割），或contain（保持图片不变形，尽可能填充整个容器，不会切割图片）

背景图片渲染起始位置

background-position，参数是两个空格隔开的单词，(left,center,right)与(top,center,bottom)的笛卡尔积，表示渲染的起始位置。

也可以是两个百分比，或者两个整数（单位px）。

text-indent，值可以是xx px、xx em，分别是以像素、汉字字数为单位进行首行缩进。

CSS盒子模型

盒子模型

每一个HTML元素都可以看作一个盒子模型（Box Model），包括它自己、内边距、边框、外边距。

如下图:

弹性盒子模型（CSS3新特性）

弹性盒子主要应用于，一个大盒子里存放很多小盒子时进行弹性布局以适应不同显示终端。
将外层盒子的display属性设置为flex实现一个弹性盒子模型，可以更好地管理内部的布局。

Flex 布局中有两条轴：

  • 主轴（main axis）：默认水平方向，从左到右。
  • 交叉轴（cross axis）：默认垂直方向，从上到下。

可以通过 flex-direction 属性改变主轴方向。

Flex 容器属性

以下属性需设置在父容器（flex container）上。

1. flex-direction —— 主轴方向

  • row（默认）：水平方向，起点在左。
  • row-reverse：水平方向，起点在右。
  • column：垂直方向，起点在上。
  • column-reverse：垂直方向，起点在下。

2. flex-wrap —— 是否换行

默认所有 flex 项目会在一行内排布（即使溢出），可通过此属性控制换行。

  • nowrap（默认）：不换行。
  • wrap：换行，第一行在上方。
  • wrap-reverse：换行，第一行在下方。

3. flex-flow —— flex-direction 和 flex-wrap 的简写

4. justify-content —— 主轴对齐方式

控制 flex 项目在主轴上的分布。

  • flex-start（默认）：起始端对齐。
  • flex-end：末尾端对齐。
  • center：居中。
  • space-between：两端对齐，项目之间间隔相等。
  • space-around：每个项目两侧间隔相等。
  • space-evenly：项目之间及两端间隔完全相等。

5. align-items —— 交叉轴对齐方式（单行）

控制 flex 项目在交叉轴上的对齐。

  • stretch（默认）：拉伸填满容器高度（项目未设高度时）。
  • flex-start：交叉轴起始端对齐。
  • flex-end：交叉轴末端对齐。
  • center：交叉轴居中对齐。
  • baseline：按项目的第一行文字基线对齐。

6. align-content —— 多行交叉轴对齐方式

仅在有多行（flex-wrap: wrap 且换行）时生效，控制多行在交叉轴上的分布。
取值与 justify-content 类似：flex-start、flex-end、center、space-between、space-around、stretch（默认）。

Flex 项目属性

以下属性需设置在 flex 子元素（flex item）上。

1. order —— 排列顺序

默认为 0，数值越小越靠前。可接受负值。

2. flex-grow —— 放大比例

默认为 0，即不放大。如果所有项目都设为 1，则它们将等分剩余空间。若一个为 2，则该项目占据的剩余空间是其他项目的一倍。

3. flex-shrink —— 收缩比例

默认为 1，当容器空间不足时，项目将等比例缩小。设为 0 则不会缩小。

4. flex-basis —— 基础尺寸

在分配剩余空间之前，项目占据的主轴空间。默认值为 auto（即项目原本的尺寸）。可以设为一个固定长度（如 200px）或百分比。

5. flex —— flex-grow、flex-shrink、flex-basis 的简写

常用写法：

  • flex: 1; 等同于 flex: 1 1 0%，项目可放大可缩小，基础尺寸为 0。
  • flex: auto; 等同于 flex: 1 1 auto，项目可放大可缩小，基础尺寸为自身大小。
  • flex: none; 等同于 flex: 0 0 auto，固定大小，不伸缩。

6. align-self —— 单个项目的交叉轴对齐

覆盖容器的 align-items 属性，可取值与 align-items 相同。

常见应用场景

  • 水平垂直居中：只需在父容器设置 display: flex; justify-content: center; align-items: center;，子元素即可完美居中。

  • 响应式卡片网格：结合 flex-wrap: wrap 和 flex-basis 自动换行排列。

与 Grid 布局的区别

  • Flexbox 是 一维 布局，主要处理行或列方向上的排列。
  • CSS Grid 是 二维 布局，可同时控制行和列。

两者互补，实际开发中常常结合使用。

浮动

浮动(float)是指，使一个盒子脱离标准流（文档流），另置于一个图层之上，效果上相当于盖在底下的盒子之上。

浮动分为两种，向左浮动和向右浮动（没有上下浮动的说法）。

浮动非必要不使用，可能会造成父类盒子高度塌陷、影响到后续元素布局等。所以，浮动设置后要清除浮动：

  1. 若父元素高度塌陷，可以设置父元素的高度。

  2. 受影响的元素可以添加clear属性，设置值为both可以同时清楚左右浮动对其造成的影响。

  3. 在父元素中增加overflow: hidden，同时增加clear: both，可以使父级容器被内部浮动元素高度撑开。

定位

相对定位

相对定位的元素还在标准流当中。通过设置position为relative开启相对定位。开启了相对定位的元素可以设置其left、right、top、bottom等属性为特定像素值调整其位置。

绝对定位

绝对定位会脱离文档流。通过设置position为absolute开启绝对定位。开启了相对定位的元素可以设置其left、right、top、bottom等属性为特定像素值调整其位置。

与相对定位的区别就在于，元素脱离了文档流，会盖住其他元素。每一个绝对定位都有新的一层。

固定定位

固定定位也会脱离文档流。通过设置position为fixed开启绝对定位。开启了相对定位的元素可以设置其left、right、top、bottom等属性为特定像素值调整其位置。

固定定位会随着页面滚动而固定在屏幕某位置。

CSS3常用新特性

圆角

border-radius可以给盒子设置圆角效果，其值可以为一个百分数（100%是彻底的圆），也可以是xx px。同时也可以有多个值：

  • 四个值：分别代表左上、右上、右下、左下。

阴影

box-shadow: h-shadow v-shadow blur color，四个值分别代表竖直方向的阴影移动，水平方向的阴影移动，阴影模糊度、阴影的颜色。

性能

  • 优先使用 transform 和 opacity 进行动画，因为它们由 GPU 加速，性能更好。
  • 避免动画触发页面重排（如改变宽高、边距等），会消耗性能。
  • 使用 will-change 属性提示浏览器提前优化（但要适度，不要滥用）。

媒体查询

媒体查询是 CSS3 的核心特性之一，用于实现响应式设计。它允许我们根据设备的特性（如屏幕宽度、高度、分辨率、方向等）应用不同的 CSS 样式，从而让同一个网页在不同设备上呈现出最佳的视觉效果。

简单来说，有了媒体查询，你写的页面就能同时适配电脑、平板和手机。

视口（Viewport）设置

在使用媒体查询之前，务必在 HTML 的 <head> 中加上视口设置，否则移动端浏览器可能会按桌面端宽度渲染，导致媒体查询失效。

  • width=device-width：让页面宽度等于设备的屏幕宽度。
  • initial-scale=1.0：初始缩放比例为 1。

基本语法

  • 媒体类型：通常设为 screen（屏幕），也可用 all（所有设备）、print（打印机）等。
  • 媒体特性：最常用的是 max-width（最大宽度）和 min-width（最小宽度），还有 orientation（屏幕方向）等。

移动优先与桌面优先

  • 移动优先（Mobile First）：先写小屏样式，再用 min-width 逐步扩展到大屏。这是目前的主流做法。

  • 桌面优先（Desktop First）：先写大屏样式，再用 max-width 逐步缩小到小屏。

推荐使用移动优先，因为移动端用户占比越来越高，且 min-width 的写法更符合渐进增强的理念。

  • pointer: coarse | fine：指点设备精度，触屏为 coarse，鼠标为 fine。
