在AI时代，或许我们再也不需要人工写html了，但是，html总要有人能看得懂，否则若干年后，html5标签语言就变成古埃及楔形文字，成为考古学家的难题了（笑）。

所以，即使在AI时代，我也坚持手搓（包括本文），希望能记录下来我能想到的常用的html5的标签，以便自己梳理和他人使用。

我自知水平有限，如有纰漏，敬请谅解。

HTML5文档结构

标题 <h1></h1>

标题从<h1></h1>到<h6></h6>，字号依次减小。正确使用标题标签有助于SEO优化。

快捷键h$*6可以快速生成从<h1></h1>到<h6></h6>的标题标签。

段落 <p></p>

段落用于包裹一段文字。两对段落标记之间会自动换行。

如果想在一段内部换行，可以使用<br>单标签。

另外，水平线单标签<hr>可以生成一条水平的分割线，它可以设置一些格式。
color是颜色，size是线的粗细，width是线的长度。（事实上，可以使用align分别为left、center、right设置线条的对齐方式，但不推荐这样做，更规范的做法是使用CSS设置。）

图片 <img src="" alt="" width="" title="">

src表示要显示的图片的路径（支持相对路径、绝对路径，真实项目里当然是使用相对路径，起点是html文件所在的目录位置）。

alt表示“alternative”，当图片损坏或不存在导致无法加载时，会显示alt设置的字符串代替。

width设置图片宽度，单位是像素(px)。当然也有height，但两者同时设置会导致图片被拉伸或压缩，一般只设置一个，另一个随比例缩放。

title是鼠标停留在图片上时显示的图片的名字。

超链接 <a href=""></a>

需要设置超链接的内容被<a href=""></a>包裹，可以是一段文字，也可以是图片等。其中，href设置超链接的目标的地址，可以是网络地址、路径、页面内的锚点、邮件、电话、JavaScript伪协议等很多。

有序列表与无序列表

有序列表 <ol></ol>

序号可选的type有1,a,A,i,I，分别表示阿拉伯数字、小写字母、大写字母、小写罗马数字、大写罗马数字。

无序列表 <ul></ul>

前缀头可选的type有disc,circle,square,none，分别表示默认实心圆、空心圆、方块、不显示。

文本

文本标签有六种（都是双标签）：<span>、<em>、<i>、<b>、<strong>、<del>，分别表示无特定含义、着重、斜体、加粗、强调、删除六种。（实际上显示出来的只有无效果、斜体、加粗、删除四种效果，但正确使用文本标签有助于SEO优化。而更多的文本效果通过CSS设置。）

表格 <table></table>

表格基本骨架

表格由<table></table>容纳，行标签<tr></tr>，列标签<td></td>，由行标签嵌套列标签实现表格的构造。另有快捷生成的方式：table>tr*n>tr*m{text}，会生成 nnn 行 mmm 列的表格，每一格内部文本由{}内的文本text填充。

可以设置：框线像素border、宽度width、高度height。但不推荐这样做，更好的做法是使用CSS设置。

Form表单

表单是网页与用户交互的重要方式，常用于登录、注册、搜索、设置等场景。表单由<form>标签包裹，内部包含各种输入控件（文本框、密码框、单选按钮、复选框、按钮等），用户填写后提交数据到服务器。

基本结构

action：指定表单数据提交到的服务器地址（URL）。
method：提交方式，常用GET（数据附在URL后，可见，有长度限制）和POST（数据在请求体中，相对安全，无长度限制）。

其他常用属性

  • required：必填，提交时若为空则阻止提交并提示。
  • readonly：只读，不可修改。
  • disabled：禁用，无法操作且提交时忽略。
  • maxlength：最大字符数。

使用 <label> 标签

<label> 用于关联文本与控件，提高可用性（点击文本即可聚焦到对应控件）。两种关联方式：

  1. 包裹控件（隐式关联）：如上文示例，直接用<label>包裹输入框。
  2. 通过 for 属性（显式关联）：<label for="id名">，控件需有对应的id。

块级元素与行内元素

在HTML中，元素根据其默认的显示方式分为两大类：块级元素（Block-level Elements） 和 行内元素（Inline Elements）。理解它们的区别是构建页面布局的基础。

块级元素

独占一行，默认宽度为父容器的100%。

可以设置 width、height、margin、padding 等盒模型属性。

通常用于页面结构划分，如段落、标题、列表、容器等。

常见块级元素：
<div>、<p>、<h1>~<h6>、<ul>、<ol>、<li>、<table>、<form>、<header>、<footer>、<section>、<article> 等。

行内元素

不会独占一行，与其他行内元素在同一行排列，直到一行放不下才换行。

宽度和高度由内容决定，设置 width 和 height 无效（除非改变 display）。

只支持水平方向的 margin 和 padding（垂直方向虽然可以设置，但不会影响其他元素的位置，可能会重叠）。

常见行内元素：
<span>、<a>、<img>、<input>、<label>、<button>、<em>、<strong>、<i>、<b> 等。

容器标签 <div></div>

<div> 是 HTML 中最基础、最通用的块级容器元素。它本身没有语义含义，仅作为一个“盒子”来承载其他内容，配合 CSS 和 JavaScript 实现布局、样式和交互。

<div> 是 Division（分割）的缩写。
它是一个块级元素，默认独占一行，宽度自动填满父容器。
它没有任何默认样式（除了浏览器可能赋予的 display: block），因此非常适合作为布局的“骨架”。

使用<div>有很多好处，如：

分组：将相关的元素包裹在一起，便于统一管理样式或行为。

布局：结合 CSS（如 Flexbox、Grid、浮动等）构建网页结构。

脚本操作：给 <div> 添加 id 或 class，方便 JavaScript 进行 DOM 操作。

HTML5 新增标签

HTML5 引入了大量新标签，旨在让网页结构更清晰、语义更丰富，同时增强多媒体和交互能力。这些新标签不仅有助于 SEO 和可访问性，也简化了开发者的工作。

多媒体标签

HTML5 之前，嵌入视频和音频需要依赖 Flash 等第三方插件。现在原生支持。

<video>：嵌入视频文件。

  • 属性：src、controls（显示播放控件）、autoplay、loop、muted、poster（封面图）、width/height。
  • 支持格式：MP4、WebM、Ogg。

<audio>：嵌入音频文件。

  • 属性：src、controls、autoplay、loop、muted。
  • 支持格式：MP3、WAV、Ogg。

<source>：为 <video> 或 <audio> 指定多个备选格式，浏览器选择第一个支持的。

<track>：为视频添加字幕或描述。

表单增强标签

HTML5 为表单新增了更多输入类型和属性，提升用户体验和数据验证能力。

新输入类型（type）

  • email：邮箱格式，移动端会调出适合输入邮箱的键盘。
  • url：网址格式。
  • number：数字输入，可配合 min、max、step。
  • range：滑块选择。
  • date、time、datetime-local、month、week：日期时间选择器。
  • color：颜色选择器。
  • search：搜索框，部分浏览器会显示清除按钮。
  • tel：电话号码输入。

新表单属性

  • placeholder：占位文本。
  • required：必填。
  • autofocus：自动聚焦。
  • autocomplete：自动补全。
  • pattern：正则验证。
  • multiple：允许上传多个文件（<input type="file">）。
  • formaction、formmethod 等，覆盖 <form> 的默认属性。

其他实用标签

  • <meter>：表示度量值（如进度、打分），有 min、max、value、low、high、optimum 属性。
  • <progress>：表示任务进度，有 value 和 max 属性。
  • <details> 和 <summary>：创建可折叠的细节区域，<summary> 提供标题，点击展开/收起。
  • <mark>：高亮文本。
  • <time>：表示日期或时间，便于机器解析。
  • <output>：显示计算结果，通常与表单配合。
  • <datalist>：为输入框提供预定义选项列表（类似自动补全）。
  • <keygen>（已废弃）、<command> 等较少使用。

兼容性注意

所有现代浏览器（Chrome、Firefox、Safari、Edge）都完全支持 HTML5 新标签。

对于旧版 IE（如 IE8 及以下），可使用 HTML5 Shiv 脚本让这些标签可被样式化。

语义化标签不会影响页面样式，但有助于 SEO 和可访问性（ARIA）。
