JAVA输入输出简介

Java 的 I/O（输入/输出）操作主要通过java.io和java.nio包提供支持。核心概念是流（Stream）：所有输入输出都被抽象为数据从一个地方流向另一个地方。根据处理数据类型，流分为字节流和字符流。

类型 抽象基类 特点 适用场景
字节流 InputStream / OutputStream 以字节（8-bit）为单位处理数据 二进制文件（图片、音频、视频）
字符流 Reader / Writer 以字符（16-bit Unicode）为单位，处理文本更安全 文本文件（.txt, .csv, .json）

标准输入输出（控制台输入输出）

标准流

Java 通过System类提供三个标准流：

  • System.in（标准输入流，InputStream类型）—— 用于读取控制台输入。
  • System.out（标准输出流，PrintStream类型）—— 用于打印结果到控制台。
  • System.err（标准错误流，PrintStream类型）—— 用于打印错误信息。

标准输入

Scanner

检测是否有下一个 token

hasNext()、hasNextInt()、hasNextDouble()、hasNextLine() 等
返回 boolean，用于循环读取时判断。

获取下一个 token

next()：返回下一个 token（字符串），默认以空白字符分隔。

nextInt()、nextDouble()、nextBoolean()、nextByte()、nextShort()、nextLong()、nextFloat()：读取并转换为相应类型。

nextLine()：读取当前行的剩余内容（包括空格），直到换行符。
（注意：如果之前调用了 nextInt() 等，换行符会留在缓冲区，导致 nextLine() 返回空字符串。）

close()：关闭 Scanner，释放底层资源（对 System.in 关闭后无法再次打开，一般不要关闭标准输入流）。
