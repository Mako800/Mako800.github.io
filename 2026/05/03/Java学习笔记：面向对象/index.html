什么是面向对象

类(Class)与对象(Object)，是面向对象的编程语言的一组核心关系。

类是指一套封装了数据和方法的实体的模板，而对象则是类的一个实例化。
可以理解为，类是一种品牌的圆珠笔的设计图纸，而被生产出来的一个个具体的圆珠笔实体就是圆珠笔类的一个个对象。

面向对象的编程语言，就是支持封装类的、以对象为操作主体的编程语言。Java、C++、Python等很多高级语言都是面向对象的。

接下来，我会介绍面向对象的三要素：封装、继承和多态。

封装

封装前文已经涉及过，就是要保证内部实现和数据不能被外部访问。即指将对象的属性（数据）和行为（方法）包装在一起，并隐藏内部实现细节，对外只暴露必要的访问接口（如 public 方法）。属性通常用 private 修饰，外界通过 public 的 getter/setter 或业务方法来访问和修改。

封装比较好理解，但有时在书写代码时常常会忽略，不小心写出了破坏封装性的代码（例如忘记深拷贝、忘记书写private修饰符等）。别看这是低级错误，事实上历史中很多大牛和大项目都犯过类似错误而造成了严重后果（包括Java早期的很多库都有封装性的问题）。

继承

继承是从现有类（父类/超类）派生出一个新类（子类/派生类）的机制。子类自动拥有父类的非私有属性和方法，并可以添加新的属性和方法，或重写父类的方法。

继承可以避免重复编写相同的代码，并建立层次结构，使得表达类型之间的“是一个”（is-a）关系。
这一点也指出了我们什么时候使用继承(is-a关系)。

抽象类与抽象方法

只要一个类包含了至少一个抽象方法，它就必须被定义成抽象类。不包含抽象方法的类也可以定义为抽象类。抽象类不能被实例化。抽象类和抽象方法的定义使用abstract关键字。

子类要么实现全部抽象方法，成为非抽象方法；要么实现一部分抽象方法或者干脆一个都不实现，此时它还是抽象类。

多态

多态是指同一个行为（方法）在不同的对象上有不同的实现形式。包括编译时多态（方法重载）和运行时多态（方法重写、接口引用指向实现类对象）。
